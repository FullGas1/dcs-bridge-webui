# 07 — branding header

**Status:** open (ready-for-agent)

## What to build

One or more generic, non-trademarked images at the top of the page evoking DCS and the bridge
(e.g. an abstract aircraft silhouette + a bridge/connector motif) — no official DCS World or
Eagle Dynamics logos or assets. Royalty-free or custom-made only.

## Acceptance criteria

- [ ] The page header displays at least one image at the top, above the widget grid.
- [ ] No asset used is an official DCS World / Eagle Dynamics trademarked logo or screenshot.
- [ ] The header renders correctly at both the default and a narrow (mobile-ish) viewport width
      without breaking the grid layout below it.
